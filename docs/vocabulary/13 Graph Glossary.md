# Graph Glossary

Everything in Tier 0, condensed for lookup. Terms below the line are forward references —
you'll meet them properly in later tiers, but know the words now so they don't blindside you.

---

## Core

| Term | Meaning | Note |
|---|---|---|
| **Vertex** / node | One of the "things" | [[02 Vertex and Edge|Vertex and Edge]] |
| **Edge** / arc | A connection between two vertices | [[02 Vertex and Edge|Vertex and Edge]] |
| **Adjacent** / neighbor | Joined by an edge | |
| **Incident** | An edge is incident to its endpoints | |
| **`V` / `n`** | Number of vertices | |
| **`E` / `m`** | Number of edges | |
| **Directed** | Edges have direction; `A→B` ≠ `B→A` | [[03 Directed vs Undirected|Directed vs Undirected]] |
| **Undirected** | Edges go both ways automatically | [[03 Directed vs Undirected|Directed vs Undirected]] |
| **Weighted** | Edges carry a number (cost/distance/time) | [[04 Weighted vs Unweighted|Weighted vs Unweighted]] |
| **Unweighted** | Every edge costs 1 → **BFS gives shortest path** | [[04 Weighted vs Unweighted|Weighted vs Unweighted]] |

## Structure

| Term | Meaning | Note |
|---|---|---|
| **Walk** | Any edge sequence; repeats allowed | [[05 Paths Walks and Cycles|Paths Walks and Cycles]] |
| **Trail** | Walk with no repeated **edge** | |
| **Path** | Walk with no repeated **vertex** | Length = #edges |
| **Cycle** | Path that returns to its start | Undirected needs ≥3 vertices |
| **Acyclic** | Contains no cycle | |
| **DAG** | Directed Acyclic Graph — topo sort exists **iff** DAG | [[06 Cyclic vs Acyclic and DAGs|Cyclic vs Acyclic and DAGs]] |
| **Connected** | Every vertex reaches every other | [[07 Connectivity and Components|Connectivity and Components]] |
| **Component** | One maximal connected "island" | |
| **Weakly connected** | Connected if you ignore arrow direction | directed only |
| **Strongly connected** | Everyone reaches everyone *following arrows* | directed only |
| **SCC** | Maximal strongly connected group; collapsing them yields a DAG | Tier 9 |

## Counting

| Term | Meaning | Note |
|---|---|---|
| **Degree** | Edges touching a vertex | [[08 Degree|Degree]] |
| **In-degree** | Edges pointing **in** | in-degree 0 = **source** |
| **Out-degree** | Edges pointing **out** | out-degree 0 = **sink** |
| **Handshake lemma** | Undirected: `Σ deg = 2E`. Directed: `Σ in = Σ out = E` | sanity check |
| **Leaf** | Degree-1 vertex (undirected) | [[10 Trees|Trees]] |

## Edge cases

| Term | Meaning | Note |
|---|---|---|
| **Self-loop** | Edge from a vertex to itself | [[09 Self-Loops and Multi-Edges|Self-Loops and Multi-Edges]] |
| **Multi-edge** | Two+ edges between the same pair | breaks `set` adjacency |
| **Simple graph** | No self-loops, no multi-edges | **assume by default** |
| **Multigraph** | Multi-edges allowed | |

## Special shapes

| Term | Meaning | Note |
|---|---|---|
| **Tree** | Connected + acyclic + `V-1` edges (any 2 imply the 3rd) | [[10 Trees|Trees]] |
| **Forest** | Disjoint set of trees; `E = V - components` | |
| **Rooted tree** | A tree with a chosen top, giving parent/child/depth | |
| **Sparse** | `E ≈ O(V)` — almost all real graphs | [[11 Dense vs Sparse|Dense vs Sparse]] |
| **Dense** | `E ≈ O(V²)` | |
| **Complete graph `K_n`** | Every pair connected; `V(V-1)/2` edges | max density |
| **Implicit graph** | Neighbors generated by a rule, never stored | [[12 Implicit Graphs|Implicit Graphs]] |

## Forward references (later tiers)

| Term | Meaning | Tier |
|---|---|---|
| **Subgraph** | A graph made from a subset of `V` and `E` | — |
| **Spanning tree** | A tree subgraph touching **all** `V` vertices | 8 (MST) |
| **Bipartite** | Vertices split in two groups; every edge crosses between them | 4 |
| **Topological sort** | Linear ordering respecting all directed edges | 4 |
| **Bridge** | Edge whose removal increases the component count | 9 |
| **Articulation point** | Vertex whose removal increases the component count | 9 |
| **Eulerian path** | Uses every **edge** exactly once (needs exactly 0 or 2 odd-degree vertices) | 9 |
| **Hamiltonian path** | Visits every **vertex** exactly once — **NP-hard**, means bitmask DP | 10 |

> Euler vs Hamilton is a common mix-up: **Euler = edges, Hamilton = vertices.** Euler is
> easy (a degree check). Hamilton is NP-hard. If a problem needs "visit every node once"
> and `n ≤ 20`, that `n` is the hint — it's bitmask DP, not a greedy walk.
